# Retired plans

Executed or superseded `wave*.yaml` plans, kept for provenance. `_plan_entries` globs the
directory above this one and not this one, so nothing here feeds the novelty catalog: an
idea that still matters must live on as a task, or as a proposal in `proposals/archive/`.

- `wave7.yaml` — the 80 WAVE1.md candidates, hand-transcribed. Superseded by the `external`
  proposal wave, which holds the same 80 in the proposal format and can be fanned out into
  a plan with `python -m reasoning_core.task_search plan`. Its `base_ref` predates
  `validation.py` and its context files have since been renamed; it is a record, not a
  runnable plan.
