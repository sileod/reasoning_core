## Level 0

### Prompt

Premise:
david is approved.
david is careful.
david is active.
david is verified.
For all x, if x is approved, then x is skilled.
Being careful implies being eligible.
Every skilled entity that is also eligible is alert.
For all x, if x is active, then x is trusted.
Whenever x is verified, x is trained.
Every trusted entity that is also trained is quiet.

Question:
Which entity can be shown to be both skilled and eligible, as well as both trusted and trained?

The answer is one entity name.


### Answer

david
