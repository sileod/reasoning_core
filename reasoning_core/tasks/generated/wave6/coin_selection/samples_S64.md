# Samples for S64 coin_selection

## Level 0

### Example 1

Prompt:

```
A till has coins of denominations 56, 44, 36, 14, 12, 1. It must make exactly 42 cents using the fewest coins possible, with any number of each denomination available. When several combinations tie at the fewest coins, pick the one whose list is lexicographically largest. What is the answer? Give a comma-separated list of coin values in decreasing order, repeating a value as often as it is used.
```

Answer:

```
14, 14, 14
```
