## Level 0

### Example 1

Query:
A binary tree has the following preorder and inorder traversals (node indices). Reconstruct the tree and report the label of the root node.

Preorder:
[0, 1, 2, 3, 5, 4]

Inorder:
[5, 3, 2, 1, 4, 0]

The answer is the root node label (a single integer).

**Answer:** 104

### Example 2

Query:

Inorder:
[1, 0, 5, 4, 3, 2]

Postorder:
[1, 5, 4, 3, 2, 0]

The answer is the root node label (a single integer).

**Answer:** 956
