# Level 0
## Example
**Prompt:**

A hidden integer x satisfies 1 <= x <= 5. Facts about x are revealed one at a time. Only the facts shown below have been observed so far.

x equals 5. x is at least 3.

Considering ONLY these observed facts, list every integer in [1, 5] that could still be the true value of x, in ascending order, separated by spaces. If no integer is consistent with the observed facts, write the single number 0.

Answer format: a space-separated list of integers in ascending order. Example: 1 3 5 or 0

**Answer:**

5
