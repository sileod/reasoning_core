## Level 0

### Example 1

**Prompt:** Let the modulus be the prime p = 2383, base g = 1210, and target h = 966. Find the smallest non-negative integer k such that g^k ≡ h (mod p). If no such k exists, answer with the single word none. The answer is that integer, or the word none.
