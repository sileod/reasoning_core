## Level 0

### Example 1

**Prompt:**

A canonical Huffman code is built from a symbol frequency table as follows. First obtain the code lengths using the usual greedy merge, breaking ties by the smaller symbol. Then assign codewords in order of increasing length and, within a length, in alphabetical symbol order.
Symbol : Frequency
a : 4
b : 6
c : 11
d : 13
e : 2

How many bits in total does the message "cebebce" occupy under the canonical Huffman code?

The answer is a non-negative integer.

**Answer:**

22
