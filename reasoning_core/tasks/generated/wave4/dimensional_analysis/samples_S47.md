# Samples S47

## Level 0
### Example 1
**Prompt:**
```
The dimensions of a physical quantity are written as a product of powers of the base dimensions M (mass), L (length), T (time) and I (electric current). A product term with exponent zero is omitted; products are written as space-separated terms, each of the form SYMBOL^EXP, with exponents as integers.
Given the following named quantities:
  impulse has dimensions M^1 L^1 T^-1
  power has dimensions M^1 L^2 T^-3
What are the dimensions of the quantity power impulse^2?
Give the answer in the canonical form described above, e.g. M^1 L^2 T^-2, omitting terms with zero exponent.
The answer is the dimension vector string.
```
**Answer:**
```
M^3 L^4 T^-5
```
