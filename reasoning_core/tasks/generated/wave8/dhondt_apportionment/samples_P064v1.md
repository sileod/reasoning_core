## Level 0

### Prompt

An election assigns 8 seats among 2 parties using the D'Hondt method. The party vote totals are [521,442]. Using the D'Hondt highest-average rule (a party receives a seat whenever its votes divided by one plus its current seats is the largest such quotient, with ties broken toward the earlier-listed party), what is the final seat vector for the parties in the same order as the vote list? Give the answer as a comma-separated list of non-negative integers inside square brackets, one seat count per party, for example [1,5].

### Answer

4,4
