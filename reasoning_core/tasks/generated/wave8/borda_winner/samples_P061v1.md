## Level 0
**Prompt:**
```
Candidates: A, B, C, D, E
Voter 1: B > D > A > C > E
Voter 2: E > B > C > D > A
Voter 3: A > D > C > E > B
Voter 4: C > B > D > A > E
Borda count: a candidate ranked position p from the top (first = 0) gets (5 - 1 - p) points per voter, where a larger number means a better rank. Sum each candidate's points across all voters, then pick the candidate with the most points. If several are tied for the most, the winner is the lexicographically smallest candidate name (the first one alphabetically).
The answer is the winning candidate's single letter.
```
**Answer:**
```
B
```
