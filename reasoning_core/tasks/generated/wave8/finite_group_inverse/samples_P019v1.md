# finite_group_inverse samples

## Level 0

### Example 1

Cayley Table:
    A  B  C  D  E  F  G
 A   C  G  D  B  F  A  E
 B   G  A  E  F  D  B  C
 C   D  E  B  G  A  C  F
 D   B  F  G  E  C  D  A
 E   F  D  A  C  G  E  B
 F   A  B  C  D  E  F  G
 G   E  C  F  A  B  G  D

Element:
D

The table above is the multiplication (Cayley) table of a finite group: the cell at row r and column c gives the product r * c of the two row/column elements. Determine the inverse of the element labeled D -- the unique element g for which D * g equals the identity element. Give only the label of that inverse element, for example 'C'.

Answer: B
