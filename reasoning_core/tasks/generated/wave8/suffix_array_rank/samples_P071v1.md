## Level 0

### Prompt

A suffix of a string is the substring that starts at some position and runs to the end. The suffix array of a string lists its suffixes in lexicographic (dictionary) order. For the string ccdccbabbacbcba, consider the suffix that starts at index 2 (0-based, so index 0 is the whole string). What is the 0-based rank of this suffix in the suffix array of "ccdccbabbacbcba"? Rank 0 means the suffix is the smallest in lexicographic order. The answer is an integer: the 0-based rank. Write only the number.

### Answer

14
