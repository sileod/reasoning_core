## Level 0
### Example 1
Lengths:
[7, 4, 5]

These are the word lengths of a binary prefix code. By Kraft's inequality a code with these lengths exists exactly when the Kraft sum sum(2^-len) is at most 1, and it never exists when the sum exceeds 1. Compute this Kraft sum as an exact reduced fraction and report it as the answer (for example "13/16", or "1" if it is an integer).
**Answer:** 13/128
