# Samples P066v1

## Level 0

### Example

**Prompt**

Each of the following agents owns one distinct item, and every agent has a strict preference ranking of all the items (most preferred first). Using the Top Trading Cycles algorithm, each agent points to their most preferred remaining item, every item points to its owner, cycles are found and their members receive the item they point to, and the members of each cycle are removed along with their items; this repeats until every agent has an item.

Agent 1 owns item A and ranks the items from most to least preferred as: E, C, D, A, B.
Agent 2 owns item B and ranks the items from most to least preferred as: C, E, A, D, B.
Agent 3 owns item C and ranks the items from most to least preferred as: E, A, D, B, C.
Agent 4 owns item D and ranks the items from most to least preferred as: B, D, A, E, C.
Agent 5 owns item E and ranks the items from most to least preferred as: D, C, B, E, A.

After applying Top Trading Cycles, which item does Agent 1 end up assigned? 

The answer is a single letter naming that item.

**Answer**

A
