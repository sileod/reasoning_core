## Level 0
### Example 1
Prompt:

A quorum system has 7 replicas numbered 1..7. A read quorum is any set of exactly 3 replicas; a write quorum is any set of exactly 6 replicas. Every read operation must read all replicas in some read quorum, and every write must be applied to all replicas in some write quorum. In the worst case, a read quorum and a write quorum may share as few replicas as possible. Give the smallest possible number of replicas that must be shared between some read quorum and some write quorum. The answer is a single non-negative integer. For example, with 10 replicas, read size 6 and write size 7 the answer is 3.

Answer: 2
