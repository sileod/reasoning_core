## Level 0
### Example 1

**Prompt:**

```
Consider the cyclic group G = Z/4Z, the integers mod 4 under addition. Let H be the subgroup of G generated by the element 2, so H = { 0, 2 }. The left coset of H containing the element 0 is g + H = { h + 0 mod 4 : h in H }. List this left coset as a Python list of its elements in increasing sorted order over the residues 0..3. The answer is that sorted list.
```

**Answer:**

```
[0, 2]
```
