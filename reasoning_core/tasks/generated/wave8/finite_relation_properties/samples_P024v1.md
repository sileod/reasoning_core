# Level 0
**Prompt**

A relation is a set of ordered pairs over the set {0, 1, ..., 1}. The relation is shown as an adjacency matrix below where a 1 in row i, column j means (i, j) is in the relation.

[1 1]
[1 1]

State which of reflexive, symmetric, antisymmetric, and transitive hold. The answer is the comma-separated list of the properties that hold, each chosen from the words reflexive, symmetric, antisymmetric, transitive. For example "symmetric, transitive".

**Answer**

reflexive, symmetric, transitive
