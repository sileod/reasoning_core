# Level 0

**Prompt:**
```
In an approval election, voters approve any subset of the candidates. Each line below is one ballot, listing the candidates that voter approves of.

Candidates:
A B C D

Ballots:
1: A
2: C
3: C
4: C
5: B C

Count the approvals each candidate receives. Who is the winner? If two or more candidates tie for the most approvals, the one that comes first alphabetically is the winner.
The answer is the winner's letter followed by its number of approvals, formatted as LETTER N, e.g. "B 3".
```

**Answer:**
```
C 4
```
