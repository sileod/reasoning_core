## Level 0

Consider the finite partial order on the elements {a, b, c, d, e, f}. The order is specified by comparability relations, where u < v means u is strictly below v: a < d; b < f; e < b. Element x is said to be covered by element y when x < y and there is no third element z with x < z < y. List all elements that cover a, that is every y such that a < y and no element lies strictly between a and y. Give them in increasing alphabetical order separated by commas, or give the single word NONE if there are none.

The answer is:

**Answer:** d
