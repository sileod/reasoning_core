# Samples for heap_key_update (P009v1)

## Level 0

**Prompt:**

The list [9, 11, 13, 15] is the array representation of a binary min-heap (each node is at most its children). The key at index 2 (0-based) is changed to value 10, and the heap property is restored by sifting this key either up or down as needed. What is the final 0-based index of this key after the update? The answer is an integer.

**Answer:**

2
