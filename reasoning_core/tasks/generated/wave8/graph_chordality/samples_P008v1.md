# Level 0
## Example 1
**Prompt:**

An undirected graph has vertices 0 through 5. Its edges are: 0-1, 0-3, 1-2, 2-3, 2-5, 3-4.

A chord in a cycle is an edge joining two nonconsecutive vertices of that cycle. Answer whether every cycle of length at least four has a chord (that is, whether the graph is chordal).

Answer with exactly 'true' if chordal, otherwise exactly 'false <L>' where L is the length of the longest cycle of length at least four that has no chord.
Example format: 'true' or 'false 5'.

**Answer:** `false 4`
