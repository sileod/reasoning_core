## Level 0

### Prompt

Balanced ternary uses the digits T (= -1), 0 and 1, with place values the powers of 3 (..., 27, 9, 3, 1) so that a digit string d_k...d_1 d_0 denotes the value sum_i d_i * 3^i.

Compute the sum of the two balanced ternary numerals `1T1T` and `1010` using the standard carry rules, and write the result in balanced ternary. The answer is a single balanced ternary numeral.

The answer is a balanced ternary numeral (digits T, 0, 1).

### Answer

1T0TT
