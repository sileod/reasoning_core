# Samples for S34 linear_recurrences

## Level 0

### Prompt

A sequence is defined as follows: its first two values are two and nineteen; each subsequent value is the negative of the previous value minus 3 times the value before that.
What is the value of the ten-th term? (The first value is the 0-th term.)

Answer with a single integer.

### Answer

475
