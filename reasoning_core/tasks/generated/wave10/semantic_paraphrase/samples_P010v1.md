## Level 0

### Example 1

**Prompt**

The following sentence describes an event: the doctor did not draw the toy.
Rewrite this sentence so that it is in the passive voice, keeping the same participants and overall meaning and leaving every other feature (voice, polarity, tense) as it currently is unless the construction changes it.
The answer is the rewritten sentence.

**Answer**

the toy was not drawn by the doctor.
