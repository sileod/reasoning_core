# agreement_completion samples

Task: supply the correctly inflected next word despite intervening nouns, coordination, and nested relative clauses.

## Level 0

Prompt:
```
Choose the verb that agrees with the grammatical subject of the clause, ignoring any nouns that merely modify that subject. Complete the sentence below by filling the blank with the correctly inflected present-tense form of the verb shown in brackets.
Sentence: a potato near the tree  ____  every morning. (verb: run)

Write the answer as a single word: the inflected verb that fills the blank.
```

Answer:
```
runs
```
