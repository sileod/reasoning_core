## Level 0
### Example
**Prompt:**
```
Combine these modular congruence constraints into a single solution:
x ≡ 4 (mod 7)
x ≡ 4 (mod 5)
x ≡ 4 (mod 5)

If the system has a solution, give it as the least non-negative residue x and its combined modulus in the form "x mod m". If the constraints cannot all hold simultaneously, answer exactly "inconsistent". For example, for the constraints x ≡ 3 (mod 4) and x ≡ 1 (mod 2), the answer is "3 mod 4".
```
**Answer:**
```
4 mod 35
```
