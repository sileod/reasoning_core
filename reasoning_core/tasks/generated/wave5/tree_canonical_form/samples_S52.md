### Example

Tree1 Parent List:
[0,0,1,1,4,5]

Tree2 Parent List:
[2,6,0,5,0,5]

The parent list of a rooted tree gives, for each node indexed from 1 to n in order, the index of its parent (the root has parent 0). The canonical form writes a leaf as () and an internal node as (children sorted lexicographically by their own canonical strings).
Are these two trees the same shape (i.e. identical canonical forms)? The answer is exactly 'same shape' or 'different shapes'.

Answer:

same shape
